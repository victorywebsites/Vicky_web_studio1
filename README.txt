IMPORTANT IMAGE NOTE
The two PNG files are intentionally stored in the SAME ROOT FOLDER as the HTML pages. The HTML references them as:
  src="vicky-logo.png"
  src="vicky-banner.png"
Do not add "images/" to these paths unless you move the images into a folder and update every reference.

PUBLISH ON GITHUB PAGES
1. Open your repository on GitHub.
2. Upload all files in this folder to the repository root (the same level as index.html).
3. If GitHub asks about files with the same names, replace the old versions with these new versions.
4. Ensure vicky-logo.png and vicky-banner.png are uploaded too.
5. Commit the changes.
6. Open Settings > Pages and confirm deployment from the main branch and /(root).
7. Wait for deployment, then refresh your live website. If needed, hard-refresh or open it in a private tab.
